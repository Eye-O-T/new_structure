# AI CCTV 관제 화면

서버 설치 도우미·서버 제어판과 독립적으로 실행되는 PyQt 기반 CCTV 관제 화면입니다.

- `application.py`: 서버 연결 기반 메인 창, 이벤트 타임라인(`analysis_completed` 분석 완료 카드·성별/연령 요약·지연 `gpid` 갱신) 및 상세 창(`analysis_completed` 전용 분석 결과 표시, `person_appeared` 미디어·녹화 표시 분리)
- `video_worker.py`: 실시간 영상 수신, 객체 좌표 및 증분 이벤트 수집, 미확정 `gpid` 완료 이벤트의 5초 주기 보완 조회
- `settings_window.py`: 관리자 로그인과 모니터링 카메라 선택
- `management.py`: 카메라 등록·수정·화질 변경·게시 계정 전달
- `resource_monitor_window.py`: 서버 및 로컬 리소스 상태 표시

별도 UI 컨테이너를 사용하지 않으며, 화면은 External 서비스의 `/api/v1` API를 호출합니다.

화면의 사람 박스 좌표는 요청 완료 후 100ms 간격으로 다시 조회합니다. 서버의 좌표 전송 간격도 최소 100ms이며, 실제 새 위치의 갱신 속도는 탐지 주기와 통신 지연에 제한됩니다. 기본 탐지가 초당 5회라면 새 박스 위치도 최대 초당 5회 갱신됩니다. 영상과 좌표는 별도로 전달되므로 재생 영상과 정확히 동기화되지는 않습니다.
